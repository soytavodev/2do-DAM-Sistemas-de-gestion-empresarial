# Resultado de aprendizaje 1

## Resultado de aprendizaje

Identifica sistemas de planificación de recursos empresariales y de gestión de relaciones con clientes (ERP-CRM) reconociendo sus características y verificando la configuración del sistema informático.

## Criterios de evaluación

### a) Se han reconocido los diferentes sistemas ERP-CRM que existen en el mercado.

Se han identificado diferentes sistemas ERP, como SAP S/4HANA, Microsoft Dynamics 365, Oracle Fusion Cloud ERP, Odoo, Sage, ERPNext y Dolibarr. También se han revisado soluciones CRM y sistemas de gestión hotelera (PMS), como Oracle OPERA Cloud, Mews y Cloudbeds.

### b) Se han identificado los diferentes tipos de licencia de los sistemas ERP-CRM.

Se han identificado las licencias GPL, propietarias y Apache, así como diferentes modelos de distribución del software. También se ha estudiado el caso de Odoo, que permite descargar, instalar y personalizar su código fuente.

### c) Se han comparado sistemas ERP-CRM en función de sus características y requisitos.

Se han recopilado diferentes soluciones disponibles en el mercado y se han estudiado conceptos de ERP, CRM y PMS, sus aplicaciones y sus posibilidades de implementación.

### d) Se ha identificado el sistema operativo adecuado a cada sistema ERP-CRM.

Se ha estudiado una arquitectura cliente-servidor en la que el cliente utiliza un navegador web compatible con Windows, macOS y Linux, mientras que el servidor puede utilizar Linux.

### e) Se ha identificado el sistema gestor de datos adecuado a cada sistema ERP-CRM.

Se han identificado MySQL y PostgreSQL como opciones relacionales prioritarias, SQLite para prototipos y MongoDB como alternativa documental. También se han considerado soluciones personalizadas de gestión de datos.
