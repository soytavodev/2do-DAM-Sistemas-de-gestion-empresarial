b) Tipos de instalación: Se han realizado varias versiones del sistema siguiendo una arquitectura cliente-servidor, con HTML en el cliente y PHP en el servidor conectados mediante fetch. Primero se alimentó la API con datos estáticos en JSON y después con una base de datos SQLite. Para la instalación se han instalado PHP y su extensión SQLite (php-cli y php-sqlite3) y se ha puesto en marcha el sistema en local con el servidor integrado de PHP (php -S localhost:8000). Como alternativa para un entorno de explotación, el mismo proyecto puede desplegarse en un servidor Apache con PHP.    002-Instalación y configuración de sistemas …
